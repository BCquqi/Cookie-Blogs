# 动态DP概述

动态DP是解决**最优化问题**的核心算法范式。它通过**状态定义**、**状态转移**和**边界条件**三要素，将复杂问题分解为**子问题**求解，利用子问题解的**重叠性**和**最优子结构**，在**时间换空间**的代价下获得最优解。

与贪心算法的核心区别：贪心算法做出**局部最优**选择，无法保证全局最优；而动态DP通过**完整搜索子问题空间**，保证找到**全局最优解**。

## 动态DP的三要素

### 1. 状态定义

状态是对**子问题求解结果的一种记录**。如何定义状态至关重要：

- **状态的完整性**：状态必须包含原问题解所需的全部信息
- **状态的有效性**：状态空间不宜过大，也不能过于稀疏
- **状态的可表示性**：状态需要能够被计算机高效表示（通常是数组、映射等）

**状态定义的黄金法则**：先写出“考虑前 i 个元素时的结果是什么”，再反推状态转移方程。

### 2. 状态转移

状态转移是指**由已知状态推出新状态**的过程。核心思想是：

> “由小规模子问题的解，推出大规模子问题的解”

转移方程的形式多种多样，常见包括：
- **向前转移**：从当前状态推向下一个状态
- **向后转移**：从后续状态推向当前状态
- **双向转移**：同时考虑前后状态的影响

**转移方程编写技巧**：
1. 明确状态含义：`dp[i]` 表示什么？
2. 找出递推关系：`dp[i]` 如何由 `dp[j] (j < i)` 推出？
3. 验证边界情况：空集、单元素、首尾等

### 3. 边界条件

边界条件是DP递推的**起点**，必须明确：

- **最小子问题**：规模最小时的解
- **初始状态**：算法开始前的状态
- **终止条件**：何时停止递推，何时取答案

**常见边界处理**：
- `dp[0] = 初始值`（表示空集/无元素情况）
- `dp[1] = 基础情况`（仅有一个元素）
- `dp[i] = INF/0` 根据问题性质设定

## 动态DP vs 分治算法

| 对比维度 | 动态DP | 分治算法 |
|---------|--------|----------|
| **子问题关系** | 子问题**重叠**，需要记忆化/缓存 | 子问题**不重叠**，独立求解 |
| **递归方式** | 自顶向下（备忘录）或自底向上（迭代） | 完全二叉树形递归 |
| **空间复杂度** | 通常需要 O(n) 或更高存储中间状态 | 通常只需要 O(log n) 递归栈空间 |
| **时间复杂度** | O(n²) 或 O(n³) 取决于状态转移 | O(n log n) 或 O(n²) 取决于分治规模 |
| **适用问题** | 具有**最优子结构**和**重叠子问题** | 可分解为独立子问题 |

## DP套路汇总

以下是常见的**DP套路**（模式/思路），按应用场景分类：

### 1. 背包类套路

| 套路 | 问题类型 | 关键点 |
|------|----------|--------|
| **01背包** | 每个物品只能选一次 | 状态转移用**倒序**遍历防止重复计算 |
| **完全背包** | 物品可重复选取 | 状态转移用**正序**遍历允许重复计算 |
| **多重背包** | 每个物品有数量限制 | 采用**二进制拆分**或**单调队列**优化 |
| **目标背包** | 完全凑出目标值 | 鰲 `dp[j - w[i]] + 1` 表示“凑出j的最少物品数” |

**代码模板**：

```cpp
// 01背包（每个物品只能选一次）
for (int i = 1; i <= n; i++) {
    for (int j = V; j >= w[i]; j--) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}

// 完全背包（可重复选）
for (int i = 1; i <= n; i++) {
    for (int j = w[i]; j <= V; j++) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

### 2. 最优子结构类套路

| 套路 | 问题类型 | 关键点 |
|------|----------|--------|
| **最长递增子序列** | 求序列中最长满足条件的子序列 | `dp[i]`表示以`a[i]`结尾的最长递增子序列长度 |
| **最长公共子序列** | 求两序列的最长公共子序列 | 二维DP：`dp[i][j]`表示考虑前i, j个元素的LCS长度 |
| **最短路径** | 求图中最短路径 |  Floyd/ Dijkstra/ SPFA 本质都是DP |
| **矩阵链乘法** | 决定矩阵乘法顺序最省运算 | `dp[i][j]`表示矩阵i..j的最小代价 |

**典型转移方程**：

```cpp
// LIS: dp[i] = max(dp[j] + 1) for j < i and a[j] < a[i]
for (int i = 1; i <= n; i++) {
    dp[i] = 1;
    for (int j = 1; j < i; j++) {
        if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
    }
}
```

### 3. 状态压缩套路

| 套路 | 适用场景 | 关键点 |
|------|----------|--------|
| **位DP** | 状态空间是 [0, 2^n) 的整数集合 | 用整数的每一位表示一个状态，`1 << i` 表示第i个状态 |
| **滚动数组** | 只与前几层状态有关 | 用两个一维数组交替，或 `i & 1` 取模 |
| **时间戳清理** | 需要撤销操作（如CDQ分治） | 记录修改位置，最后统一清零 |

**位DP代码模板**：

```cpp
// 状态是n个元素的子集情况
for (int state = 0; state < (1 << n); state++) {
    // 统计state中选了多少个元素
    int cnt = __builtin_popcount(state);
    // 转移：从state去掉最后一个1
    int last = __builtin_ctz(state); // 取出最低位的1
    int prev = state ^ (1 << last);
    // 进行转移
    dp[state] = dp[prev] + cost[last];
}
```

### 4. 数位DP套路

| 套路 | 问题类型 | 关键点 |
|------|----------|--------|
| **数位DP** | 计算在区间 [L, R] 中满足条件的数的个数 | 逐位枚举，使用 memoization 缓存中间结果 |
| **状态压缩+数位** | 元素无重复使用限制的排列/组合 | 在数位DP基础上加状态压缩 |

**数位DP代码模板**：

```cpp
// f(pos, status, limit) 表示：
// pos：当前处理到第pos位（从高位开始）
// status：当前状态（如：已用过的数字、满足的条件等）
// limit：是否受限于原数字的对应位

int f(int pos, int status, bool limit) {
    if (pos == -1) return 1; // 已经处理完所有位，满足条件
    
    int up = limit ? a[pos] : 9; // 当前位最大可选值
    int res = 0;
    for (int i = 0; i <= up; i++) {
        bool next_limit = limit && (i == up);
        res += f(pos - 1, status | (1 << i), next_limit);
    }
    return res;
}
```

### 5. 区间DP套路

| 套路 | 问题类型 | 关键点 |
|------|----------|--------|
| **区间DP** | 操作区间、合并区间、划分区间 | `dp[l][r]`表示区间 [l, r] 的最优解 |
| **区间合并** | 如矩阵链乘、括号匹配 | 通过 `dp[i][k] + dp[k+1][j] + cost` 合并 |
| **区间搜索** | 区间可达性、区间覆盖 | 通常结合BFS/DFS与DP |

**区间DP模板**：

```cpp
// 按区间长度枚举
for (int len = 1; len <= n; len++) {
    for (int i = 1; i + len - 1 <= n; i++) {
        int j = i + len - 1;
        dp[i][j] = INF;
        for (int k = i; k < j; k++) {
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i, j));
        }
    }
}
```

### 6. 斜率优化/二分DP套路

| 套路 | 适用条件 | 关键点 |
|------|----------|--------|
| **单调队列优化** | DP转移方程单调性质 | 将 `dp[j] + C[j]` 维护在单调队列中 |
| **分段单调性** | 转移方程满足 quadrangle inequality | 二分查找转移点，将 O(n²) 优化至 O(n log n) |

**单调队列优化模板**：

```cpp
deque<int> q;
for (int i = 1; i <= n; i++) {
    // 维护队列单调递增
    while (!q.empty() && dp[q.back()] >= dp[i]) q.pop_back();
    q.push_back(i);
    
    // 队首是最优解
    dp[i] = dp[q.front()] + C[i];
    
    // 越界清理
    if (q.front() <= i - k) q.pop_front();
}
```

## 算法设计步骤

### 步骤 1：问题分析

1. **确定问题性质**：是否具备重叠子问题和最优子结构？
2. **确定输出形式**：最终需要什么样的结果？
3. **确定输入规模**：问题的数据规模是多少？

### 步骤 2：状态定义

1. **定义状态变量**：`dp[i]` 表示什么？
2. **确定状态空间**：有多少个状态？状态间的依赖关系？
3. **考虑边界情况**：最小子问题如何定义？

### 步骤 3：推导转移方程

1. **寻找递推关系**：子问题之间如何相互依赖？
2. **验证正确性**：用小规模例子手动验证转移方程
3. **考虑多种情况**：分类讨论，确保转移方程完整

### 步骤 4：实现与优化

1. **选择实现方式**：自顶向下（备忘录）或自底向上（迭代）
2. **空间优化**：能否压缩状态空间？能否使用滚动数组？
3. **时间优化**：能否使用单调队列、二分查找等技巧优化转移？

## 常见错误与避坑

| 错误类型 | 典型错误 | 避坑建议 |
|----------|----------|----------|
| **状态定义错误** | 状态不完整，导致转移方程推不出 | 多写几个例子验证状态的完整性 |
| **转移方程漏案** | 未考虑所有可能的转移情况 | 分类讨论，漏掉一种情况再补 |
| **边界条件错** | 初始值错误或终止条件错误 | 用极端情况手动测试 |
| **重复计算** | 未使用备忘录或状态重叠未处理 | 自顶向下记得加缓存，自底向上注意遍历顺序 |
| **空间不足** | DP数组开得太小或越界 | 根据最大可能的状态数开数组，注意类型边界 |

## 经典例题

### 例1：01背包（P0/1背包）

**题目**：给定 n 个物品，每个物品有重量 w[i] 和价值 v[i]，以及背包容量 V，问最多能背的价值是多少？

**状态定义**：`dp[j]`表示容量为j的背包能背的最大价值

**转移方程**：
- 不选第i个物品：`dp[j]`保持不变
- 选第i个物品：`dp[j] = max(dp[j], dp[j - w[i]] + v[i])`（j >= w[i]）

**实现**：
```cpp
for (int i = 1; i <= n; i++) {
    for (int j = V; j >= w[i]; j--) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

### 例2：最长递增子序列

**题目**：给定长度为 n 的序列 a[1..n]，求其中最长严格递增子序列的长度。

**状态定义**：`dp[i]`表示以 a[i] 结尾的最长递增子序列长度

**转移方程**：
```
dp[i] = 1 + max{dp[j] | j < i且 a[j] < a[i]}
```
若无满足条件的 j，则 dp[i] = 1

**实现 O(n²)**：
```cpp
for (int i = 1; i <= n; i++) {
    dp[i] = 1;
    for (int j = 1; j < i; j++) {
        if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
    }
}
```

**实现 O(n log n)**（ patience sorting 变体）：
```cpp
vector<int> dp;
for (int i = 1; i <= n; i++) {
    auto it = lower_bound(dp.begin(), dp.end(), a[i]);
    if (it == dp.end()) dp.push_back(a[i]);
    else *it = a[i];
}
int lis_len = dp.size();
```

### 例3：矩阵链乘法

**题目**：给定 n 个矩阵 A1, A2, ..., An，它们的维度分别为 p0×p1, p1×p2, ..., p_{n-1}×pn，问所有矩阵乘积的最小标乘次数是多少？

**状态定义**：`dp[i][j]`表示矩阵 Ai..Aj 的最小标乘次数

**转移方程**：
```
dp[i][j] = min{dp[i][k] + dp[k+1][j] + pi-1 * pk * pj}  for i <= k < j
```

**实现**：
```cpp
// 按长度枚举
for (int len = 2; len <= n; len++) {
    for (int i = 1; i + len - 1 <= n; i++) {
        int j = i + len - 1;
        dp[i][j] = INF;
        for (int k = i; k < j; k++) {
            dp[i][j] = min(dp[i][j], 
                dp[i][k] + dp[k+1][j] + p[i-1] * p[k] * p[j]);
        }
    }
}
```

## 动态DP进阶技巧

### 1. 空间压缩

当DP状态只与前 few 层有关时，可以使用：
- **一维数组优化**：从二维降为一维
- **滚动数组**：两个一维数组交替使用
- **位运算压缩**：将状态打包表示

### 2. 时间复杂度优化

- **单调队列优化**：将 O(n²) 优化至 O(n)
- **二分查找优化**：将 O(n²) 优化至 O(n log n)
- **分治优化**：结合CDQ分治，将 O(n²) 优化至 O(n log² n)

### 3. 多维DP处理

- **坐标压缩**：将稀疏坐标映射为连续整数
- **树状数组/线段树**：在二维/多维DP中维护前缀和/区间最值
- **状态转移的几何意义**：利用几何性质优化转移

## 总结

动态DP是算法设计中最重要的范式之一，其核心在于**“分治+记忆化”**的思想。掌握动态DP需要：

1. **明确三要素**：状态、转移、边界
2. **熟练套路**：背包、LIS、区间DP、数位DP等常见模式
3. **灵活优化**：空间压缩、时间复杂度优化技巧
4. **多实践**：通过大量题目积累经验，识别问题类型

**学习路线建议**：
1. 从基础背包问题入手，熟悉正序/倒序遍历的区别
2. 学习LIS问题，掌握 O(n²) 和 O(n log n) 两种实现
3. 进阶到区间DP，理解区间长度枚举的思想
4. 学习数位DP，处理区间计数问题
5. 研究高级优化技巧，如单调队列、分治优化

动态DP不仅是一门编程技巧，更是一种**系统化的问题求解思维**。掌握它，将极大提升您在算法设计和竞赛编程方面的能力。
